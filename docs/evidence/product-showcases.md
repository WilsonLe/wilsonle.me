## Viewing contract

The shared screenshot component retains image-left/caption-right rows, stacking below 900px. The two conversation-plus-app captures use the full content width with captions underneath so both panes are larger at rest.

Pangea, Kalibr, LocalCut and LocalDesign opt into image-only 1.5× hover/focus magnification and an explicit `Zoom image` control. The control opens a bounded, native-resolution scroll region, focuses it for keyboard panning, and provides `Fit image` to return. Touch users can pan by scrolling. Full-size asset links remain available. CYOBot and Vulcan stay static. Captions never scale. Reduced motion omits automatic magnification and entry animation; deliberate zoom still works without animation. No JavaScript leaves the fitted images and full-size links readable.

The former resume routes remain removed; all header, hero, mobile-menu and footer entry points download the existing one-page PDF. Theme, contact, footer, locale handling and typography fixes are preserved. No new dependencies, migrations, CMS changes or tracking scripts are introduced. No ADR is needed: the change extends the existing catalogue/renderer and uses native overflow behavior. Rollback is a scoped revert.
