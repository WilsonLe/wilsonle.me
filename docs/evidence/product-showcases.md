## UI contract and verification

All screenshots, labels, descriptions and links render on the server. A small client component observes each figure once to draw the leader line, reveal the label and settle the target ring. The observer disconnects on entry/unmount. No scroll hijacking or continuous loops. Reduced-motion CSS omits animations; unsupported observers and JavaScript-disabled browsing retain the static content. On small screens, annotation text stays above the image and leader lines are omitted for legibility. Images are never cover-cropped. Other work and return links preserve the active locale prefix; invalid locales/slugs return 404.

Focused verification: production `next build`, TypeScript, ESLint on changed TS/TSX and Prettier, plus built-in-browser checks of all three pages, image loading, section navigation, full screenshot links, mobile/tablet/desktop overflow, reduced motion, no JavaScript, homepage links, localized routes, metadata and invalid routes. Review and exact revision results are recorded in the consolidated PR. Backend/API suites, physical robot pairing and production deployment are outside this change. No ADR is needed: this extends the existing typed content/server-page pattern without a durable architectural change.
