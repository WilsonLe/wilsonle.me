## Skills carousel

Skills spans the full hero content width beneath the heading and CTA buttons at every breakpoint; desktop uses the same single-column arrangement as mobile. The same 36 technologies come from the approved `skillStack` in the full résumé at revision `f9d1363`, grouped into Frontend, Backend, Data & AI, Cloud & ops, Languages, and AI tools. No skill or proficiency is invented. AWS/Google Cloud Platform abbreviate the source's cloud-provider entries. The concise PDF is unchanged.

Icons and names form one continuous horizontal stream moving right to left at 60 CSS pixels per second. Three identical runs make wrapping seamless in either direction; duplicate runs are excluded from accessibility. Gray-shaded edge chevrons appear on mouse hover, a touch tap (four seconds), or keyboard focus. Pointer clicks briefly accelerate in their direction, easing back to the normal leftward pace. Hover, touch discovery and pointer selection keep the strip moving. Keyboard focus or key input pauses automatic movement for discrete browsing; keyboard and reduced-motion chevrons skip one skill. The Play/Pause controls and category-grid slides are removed. Named tabs below jump to each group's first skill, and the active section follows the stream with a sliding underline and color transition. Reduced motion disables autoplay and transitions; offscreen content and background pages suspend autoplay. Manual controls reach every skill. Without JavaScript, six static category lists expose all 36 names through native anchors.

Icons are local static SVGs, without a CDN or runtime dependency. `public/skills/sources.json` pins upstream commit URLs and SHA256 hashes. Thirty icons come from [Devicon](https://github.com/devicons/devicon) (MIT; notice included), four from [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0; license included). React/React Native share a mark. Pinecone uses a locally authored database glyph. Decorative icons have empty alt text beside readable names.

The footer omits location. Contact links and the PDF's approved facts remain. No new dependencies, backend changes, migrations, CMS changes or tracking scripts are introduced. No ADR is needed: native React state and browser hash navigation extend the existing server catalogue/client-leaf model. Rollback is a scoped revert.
